# NumPy & Pandas Notes 📘

My personal learning notes on NumPy and pandas, written as a Jupyter notebook 
with explanations and hands-on code examples.

## 📌 About

This notebook is a structured set of notes I'm building while learning data science in Python. Each section covers a concept with a short explanation followed by working code examples.

## 📂 Contents

- **NumPy**
  - Creating arrays
  - Indexing & slicing
  - Array operations & broadcasting
  - Aggregations & statistics

- **Pandas**
  - Series & DataFrames
  - Reading/writing data (CSV, Excel, etc.)
  - Filtering & selecting data
  - GroupBy & aggregation
  - Handling missing data

## 🛠️ Tech Stack

- Python 3.x
- NumPy
- pandas
- Jupyter Notebook

## 🚀 Getting Started

1. Clone the repo
```bash
   git clone https://github.com/theabhikushwaha/numpy-pandas-notes.git
```
2. Install dependencies
```bash
   pip install numpy pandas jupyter
```
3. Open the notebook
```bash
   jupyter notebook
```
